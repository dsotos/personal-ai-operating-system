# FAQ

## Is this a chatbot framework?

No. It is an operating model and documentation foundation. It can be implemented with Hermes Agent, another agent framework, or a combination of local scripts and services.

## Do I need a vector database?

Not at first. A well-structured human-readable knowledge base and deterministic search are often enough for a first version. Add semantic retrieval when the volume and use case justify it.

## Should I put my whole memory in GitHub?

No. Keep private memory in a private system. Publish only synthetic examples, templates, and generalized procedures.

## Can the assistant publish automatically?

It can, but the default should be human approval for public posts, messages, purchases, account changes, and destructive actions.

## Which model should I use?

The operating model should not depend on one model. Use a fast model for simple routing and formatting, and a stronger model for ambiguous research, synthesis, architecture, or high-consequence work.

## What is the most common mistake?

Starting with a giant prompt instead of defining memory ownership, workflow steps, approval boundaries, and verification criteria.

## How do I contribute?

Use fictional data, explain the problem solved, run the public safety checks, and keep provider-specific or personal deployment details out of the change.
