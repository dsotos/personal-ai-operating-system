# Workflow: source to note

## Input

A URL, document, transcript, or message containing potentially useful knowledge.

## Steps

1. Preserve the original source URL or file reference.
2. Record access date and source type.
3. Extract only claims supported by the source.
4. Summarize the useful insight in plain language.
5. Add tags, topic, and possible projects.
6. Link related notes and identify contradictions.
7. Mark whether the note is verified, provisional, or opinion.
8. Save it in the private knowledge base.

## Acceptance criteria

- Provenance is preserved.
- The note distinguishes source facts from interpretation.
- No private credentials or unnecessary personal data are copied.
- The note can be found again through its title, tags, or links.
